# Codex 协作任务总览

## 记录范围

这组笔记记录本次个人网站项目中，用户提出需求、Codex 协助实施的任务。它覆盖当前聊天中的建站、发布、视觉调整、内容板块、动画与期末报告，不代表其他项目或其他聊天的记录。

## 任务清单

- 建站部署：确认已连接的 GitHub 账号，创建个人主页仓库，上传网站并通过 GitHub Pages 发布。
- 界面设计：完成简洁个人主页、苹果设计理念风格、液态玻璃、清晰分区，并进一步调整为液态透明玻璃。
- 内容管理：添加生活相册、学习笔记，以及按模块整理的项目任务记录。
- 交互功能：添加本地备忘录、发光旋转星球与四颗环绕小星球。
- 兴趣爱好：加入音乐、旅行、运动和游戏四项内容，提供兴趣手记入口。
- 问题修复：处理公共目录 API 限流、页面缓存和重复目录记录。
- 项目交付：制作并交付 10 页期末报告的 Word 与 PDF 电子文件。
- 验证维护：记录已观察到的结果，区分代码已实现与完整链路已验证。

## 网站结构

首页包含关于、作品、生活相册、学习笔记、兴趣爱好、备忘录与联系入口。首页星球是装饰动画；内容写入通过 GitHub 完成，本地备忘录保存在当前浏览器。

## 如何阅读

使用模块筛选定位任务，或搜索标题与摘要。每篇记录依次说明任务目标、实现内容、相关文件、验证情况与学习要点。新增个人笔记仍可使用“写学习笔记”，没有模块元数据的文章归入“我的笔记”。

## 当前边界

公开照片、笔记与兴趣手记可以被访客阅读。备忘录没有云同步。当前没有独立数据库、站内账号或定时提醒。尚未完成的测试在对应笔记中单独注明。
