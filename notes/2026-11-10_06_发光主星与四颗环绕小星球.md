# 发光主星与四颗环绕小星球

## 任务目标

将首页原有银灰球体改为动态发光星球，并让若干小星球围绕它运行。

## Codex 完成的任务

- 使用蓝紫主星、表面纹理和固定明暗遮罩模拟球体自转。
- 添加四颗不同颜色、大小与速度的小星球。
- 使用轨道容器的旋转与纵向压缩形成不同倾角的椭圆运行路径。
- 添加光晕呼吸与细小星光效果。
- 实现暂停和播放按钮，以及系统减少动态效果的适配。
- 使用 IntersectionObserver 和页面可见性事件，在离开可视区或后台时暂停。
- 本次让星球场景的外壳也变得透明，与整体玻璃界面协调。

## 动画参数

主星表面周期为 24 秒。四条轨道周期分别为 14、23、31 和 11 秒，使用不同的初始相位。轨道运动使用 CSS transform，表面使用背景位置变化，所有视觉由代码生成。

## 相关文件

index.html 中的 planetarium 定义场景；styles.css 定义 planet-turn、satellite-turn 和各轨道参数；script.js 管理暂停状态；liquid-glass.css 调整透明外壳。

## 验证情况

上一版本已确认页面存在四个小星球，动画状态为 running；点击暂停后四项变为 paused，按钮文字变为播放动画。手机宽度下已观察到主星、轨道与小星球。系统减少动态效果和所有设备性能尚未完整实测。

## 学习要点

这是 CSS 实现的视觉模型，没有使用真实天体数据或物理仿真。装饰动画应提供暂停入口，并在不可见时减少运行。
