# 生活相册与照片空间

## 任务目标

开辟能够保存公开照片、记录美好生活的相册板块。

## Codex 完成的任务

- 创建 photos 目录与“上传照片”入口。
- 按生成目录筛选 JPG、JPEG、PNG、WebP、GIF 和 AVIF 文件。
- 从“日期_说明.扩展名”中提取卡片时间和标题。
- 实现图片延迟加载、失败反馈、大图对话框、上一张和下一张按钮。
- 为大图提供方向键切换及关闭操作。
- 明确提示相册照片会公开展示。

## 使用方式

点击上传入口，登录 GitHub 后选择照片并 Commit changes。文件可命名为“2026-11-10_今天的晚霞.jpg”。等待 Pages 发布后刷新相册。

## 存储方式

照片保存在公开仓库，网页读取构建生成的目录，再加载原始图片。这不是站内独立上传服务器；网页不会自行持有用户的 GitHub 写入令牌。

## 相关文件

photos 目录保存照片；collections.json 生成目录；script.js 提供 loadPhotos 和 showPhoto；index.html 提供相册区域及对话框。

## 验证情况

相册空状态与目录读取已在网页中显示。尚未使用用户真实照片完成“上传 → 构建 → 卡片 → 大图切换”的完整链路测试。没有自动图片压缩、HEIC 转换或 EXIF 日期读取；建议单张压缩至 5 MB 以内，这属于使用建议，不是代码强制限制。

## 学习要点

图片展示与图片存储是两件相关但不同的工作。公开相册应明确可见范围，并考虑图片尺寸、失败反馈和加载时机。
